Bot file requirements

  • Your bot entry file must be named bot.js, bot.py, bot.rb, or bot.lua.
  • Download the matching TvCord.* API library from this portal and import it in your bot file. Keep both files in the same folder.
  • The selected language must match the file extension.
  • Keep the bot token private and use a secret/environment variable on your host.
  • Do not upload passwords, API keys, or other secrets inside the source file.
The TvCord API files connect your bot to the TvCord gateway. The gateway must be deployed in Supabase and the bot SQL migrations must be installed before live bot features work.

By registering a bot, you agree to follow the Terms of Service and Privacy Policy. Bot source is read only to validate its filename, language marker, and size; the source is not stored by the portal.
