# TvCord

**TvCord is a community chat website for friends, groups, and shared interests.** It brings servers, channels, conversations, profile customization, and image sharing together in a dark, easy-to-use interface.

## What you can do

- Create a server for your friends or community, or join one using an invite code.
- Chat in real time in the channels you belong to.
- Share images, GIFs, and supported files.
- Choose a display name, profile avatar, status message, and accent color.
- Use TvCord in a modern browser on a phone, tablet, Chromebook, or desktop.
- Enjoy TvCord's included customization features without a separate premium subscription.

Animated profile pictures work when you upload a supported GIF and your browser displays it normally. Storage and upload limits depend on the service configuration. Some features found in other chat platforms—such as voice calling, animated banners, and advanced profile themes—may not be available in this version yet.

## Open TvCord

When the site has been published, open the project's GitHub Pages address in your browser:

**https://tvmanisback.github.io/TvCord/**

You do not need to download a desktop app or run a server on your computer. If the site is not yet live, ask the person managing TvCord to finish the one-time website setup.

## Create an account or log in

1. Open TvCord in your browser.
2. Choose **Create an account** if this is your first visit.
3. Enter your display name, email address, and a password.
4. If email confirmation is enabled, check your inbox and confirm your address.
5. Return to TvCord and log in with the same email and password.

Keep your password private. TvCord staff should never ask you to send it in a chat message.

## Create or join a server

- **Create:** Select the plus button in the left server rail, enter a server name, and create it. A general text channel is created automatically.
- **Add a channel:** Select the plus beside Text Channels, then choose a channel name.
- **Invite friends:** Open the server name menu or Invite & server info, then copy the invite code and send it only to people you want to invite.
- **Join:** Select the compass button, paste an invite code, and choose Join server.
- **Switch:** Select a server icon in the far-left rail. Select a channel to open its conversation.

Treat invite codes like invitations to your space: anyone who has a valid code may be able to join.

## Chat and share files

1. Open a server and select a text channel.
2. Type your message in the box at the bottom and press Enter or select the send icon.
3. Use the image button or plus button to attach a supported file.
4. Select a picture attachment to view it in a larger view.

Messages appear as other people send them. TvCord currently supports text chat and file/image sharing; a voice-channel label does not mean live voice calls are available.

## Customize your profile

1. Select your avatar or the settings icon next to your username.
2. Change your display name, status, or accent color.
3. Select Change avatar to upload an image or GIF.
4. Select Save profile to save your text and color changes.

Use an image you have permission to share. Profile images are publicly viewable in this version, so do not upload private or sensitive pictures.

## Troubleshooting

- **The site says it needs Supabase setup:** TvCord's site has been published, but its service connection has not been configured yet. Contact the person who manages the site.
- **You cannot log in:** Check the email and password, and confirm your email if requested.
- **A server invite does not work:** Ask the sender to copy the current invite code again.
- **An upload fails:** Try a supported image or file smaller than the current upload limit.
- **Messages do not update:** Refresh the page and check your connection. If the issue continues, contact the site manager.

## Be kind and stay safe

Do not share your password, private information, or an invite code publicly unless you intend the server to be open. Block/report tools and voice calls are not implemented in this version, so use care when joining communities.
